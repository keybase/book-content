# Keybase.pub

Keybase.pub (`https://keybase.pub` and `https://username.keybase.pub`) was a proof-of-concept site that served files from `/keybase/public`. It was discontinued in March 2023.

To host a static site from Keybase today, use [Keybase Sites](/sites) with a custom domain (`kbpbot`). See also [custom domains](/sites#custom-domains).

Public folders themselves (`/keybase/public/...`) will shut down in December 2026. Copy anything you need to keep. Private and team folders are not affected.
